# Amazon Homepage Clone

## 📌 About the Project

Amazon Homepage Clone is a frontend web development project inspired by the Amazon shopping website. It recreates the basic layout and visual appearance of an online shopping homepage using HTML and CSS.

The project includes a navigation bar, search section, shopping categories, product images, and promotional content.

## 🎯 Objectives

- Learn the fundamentals of HTML and CSS.
- Understand website layout and styling.
- Practice Flexbox and CSS Grid.
- Create a shopping website interface inspired by Amazon.
- Improve frontend development skills.

## ✨ Features

- **Navigation Bar:** Displays the logo, delivery location, search bar, account section, returns and orders, and shopping cart.
- **Category Panel:** Includes shopping navigation options and promotional text.
- **Hero Section:** Displays a promotional banner with a background image.
- **Gaming Section:** Features a gaming-related shopping card.
- **Fashion Section:** Displays jeans, tops, dresses, and shoes in a 2×2 image grid.
- **Hover Effects:** Adds border and link hover styling.
- **Font Awesome Icons:** Uses icons for location, search, menu, and shopping cart.

## 🛠️ Technologies Used

- **HTML5** – Creates the structure of the webpage.
- **CSS3** – Handles styling, layouts, colors, spacing, and hover effects.
- **CSS Flexbox** – Aligns navigation items and shopping sections.
- **CSS Grid** – Organizes fashion products into a two-column grid.
- **Font Awesome** – Provides icons for the navigation bar.
- **Image Assets** – Adds the logo, banner, and product images.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the `amazon-main` folder in Visual Studio Code.
4. Open `project.html`.
5. Right-click the file and select **Open with Live Server**, if the Live Server extension is installed.
6. View the homepage in your browser.

**Note:** An internet connection is required to load Font Awesome from its CDN.
